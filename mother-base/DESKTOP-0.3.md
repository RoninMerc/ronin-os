# TRL Mother Base 0.3.0 — desktop refresh

## Install
Close Mother Base and run TRL-Mother-Base-Setup-0.3.0.exe over the existing installation. Keep the same Windows account. Saved service URLs, encrypted keys and cached data are retained. Existing phone apps and the Render service need no changes for this desktop update.

## What changed
- Dark TRL interface with red accents, a persistent sidebar and an operations overview.
- Readable tables for patrol duty/GPS, SilverTrack activity, breach history and imports needing review.
- Registration-sorted vehicle register with search across registrations, vehicle details and addresses.
- Selected vehicle and source-report details appear in readable panels.
- Checkpoint configuration keeps its existing fields and adds a QR-photo attachment indicator.
- Connection states distinguish connected services from saved offline data.
- Pairing codes use a selectable monospace field and a Copy code button.
- Existing vehicle edits, deletion audit, per-device pairing, checkpoint revision protection, cloud API and DPAPI settings are retained.

## Verification
The Windows workflow verifies startup, unattended installation, installed startup, registration sorting/search, record preservation, report-table projections and seven-page navigation/rendering before publishing this release. Screenshots use explicitly labelled sample data.

Live SilverTrack detail capture still requires acceptance against the authorised Master session. This desktop refresh does not claim that the real report import has been verified.

Windows 10/11 x64. Includes the .NET runtime. Installer is not Authenticode-signed.
