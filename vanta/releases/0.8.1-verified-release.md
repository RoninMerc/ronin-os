## Genuine remaining boundaries

No provider keys or physical phone were available for live paid generation, microphone/camera/Bluetooth or model-driven compiler repair verification. No unconditional 100% reliability or commercial-value claim is made.

Android Forge requires the phone's own scoped GitHub credential for the existing worker. That worker performs real Gradle compilation and lint; it does not provide generated-app unit/runtime test results. Vanta reports those as not run. The repair loop is bounded to three actual attempts.

Windows source generation/editing exists, but no Windows compiler endpoint is configured in this integration. It reports a blocked state with retained source and never fabricates an EXE. Project imports remain subject to the existing 150-file / 4 MB expanded worker contract. API catalogue visibility cannot provide models or account permissions not exposed by the provider.
